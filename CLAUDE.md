# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Current State

`Marlo-hf/projetossdria` is a collection of independent marketing/design deliverables for Unlockify Digital
(an agency doing paid traffic, automation and AI for law firms). There is no shared build system; each folder
stands on its own. Content and file names are in Brazilian Portuguese.

- `guia-agro/`: A4 PDF guide built from HTML (`node build.js`, then `print.js` to render the PDF).
- `stand-evento/`: event stand files (vector logo + 2 x 2.5 m backdrop), generated by `python3 stand-evento/gerar.py` (`--previa` renders quick PNGs to /tmp for layout iteration).
  See `stand-evento/LEIA-ME.md` for print specs and dependencies.

## Brand

- Colors: lilac `#9084D8`, navy `#161827`, white. Font: Inter (Bold for "Unlockify", Medium wide-tracked for "DIGITAL").
- Logo geometry is reconstructed in `stand-evento/gerar.py` (`simbolo_d`, `assinatura`); reuse it instead of redrawing.
- Print files: outline text, expand strokes, export CMYK. Ghostscript's CMYK conversion rasterizes gradients and
  turns the navy gray, so `gerar.py` converts colors itself (`pdf_para_cmyk`).

## Guidance for Future Sessions

- Inspect the specific folder before assuming tooling; there are no repo-wide lint or test commands.
